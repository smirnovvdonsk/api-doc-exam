# Быстрый старт

1. Зарегистрируйтесь в личном кабинете.
2. Получите [API-токен](авторизация.md). Токен позволит получить доступ к <Название сервиса> API. Система токенов позволит вам контролировать, кто и как взаимодействует с вашими данными через API.
3. Отправьте первый запрос. Для создания нового пользователя:

- выберите метод POST
- заполните тело запроса, как показано ниже
- нажмите **Execute**

```
{
  "username": "Sema",
  "email": "<произвольный email>",
  "firstName": "Семен",
  "lastName": "Семенов",
  "address": {
    "country": "РФ",
    "city": "Москва",
    "street": "Тверская",
    "house": "1"
  },
  "age": 15,
  "isEmployee": true,
  "accountStatus": "active"
}
```

В случае успешного выполнения запроса будет выведено сообщение

```
201 	Пользователь успешно создан

{
  "id": <id пользователя>,
  "username": "string",
  "email": "string",
  "firstName": "string",
  "lastName": "string",
  "address": {
    "country": "string",
    "city": "string",
    "street": "string",
    "house": "string"
  },
  "age": 0,
  "isEmployee": true,
  "accountStatus": "active"
}
```
