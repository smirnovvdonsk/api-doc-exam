# vuepress-template-ru

Домашнее задание №3 по документированию API

Node.js >= 22

## Dev-сервер

1. (не обязательно) Создать конфигурацию окружения:

```sh
cp ./.env.development.template ./.env.development
```

... и заполнить созданный файл `.env.development`.

2. Запустить dev-сервер:

```sh
npm install
npm run dev
```

## Сборка в продакшн

1. (не обязательно) Создать конфигурацию окружения:

```sh
cp ./.env.production.template ./.env.production
```

... и заполнить созданный файл `.env.production`.

2. Собрать:

```sh
npm install
npm run build
```
